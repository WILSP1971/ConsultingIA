# PROMPT-001 — Ejemplo de prompt optimizado (plantilla)

> Producido por XAVIER a partir del objetivo en bruto del Lead. Sirve de ejemplo.

## Contexto
Proyecto de software con CHECKPOINTS estrictos: borrado lógico, herencia de BaseData,
sin secretos en texto plano, criterios de aceptación verificables.

## Rol
Arquitecto de software senior (lo resolverá DOCTOR STRANGE → CAPTAIN AMERICA).

## Acción
Crear el módulo de pagos con su capa de pruebas.

## Restricciones (CHECKPOINTS)
- C2 borrado lógico · C3 secretos en variables de entorno · C4 criterios verificables.

## Formato de salida esperado
1. Supuestos explícitos.
2. Plan por pasos.
3. Criterios de aceptación verificables.
4. Riesgos y dependencias.

## Criterios de éxito
- [ ] El plan cubre casos felices y de error.
- [ ] Cada criterio es medible (entrada → salida esperada).
- [ ] No hay secretos en el código.

## Preguntas abiertas para el Lead
1. ¿Qué pasarela de pagos se usará?
2. ¿Se requieren reembolsos en esta primera versión?
